# Bellhaven Sync

This project implements the Bellhaven CRM reconciliation pipeline.

## Components

### 1. Scraper
Scrapes Bellhaven communities from the website and outputs:
- name
- address
- city
- state
- zip
- care offerings

### 2. Matcher
Matches scraped locations to CRM accounts using:
- deterministic matching (city/state/name normalization)
- fuzzy matching (string similarity)
- classification into:
  - confident match
  - match needing fix (name or parent)
  - new account needed
  - CRM orphan
  - duplicate

### 3. Review App
Local Flask UI showing:
- each proposed change
- evidence (website vs CRM)
- approve/reject buttons

Approved changes write back to CRM via API.

### 4. CRM Client
Simple wrapper around GET, POST, PATCH.

### 5. Scheduler
Daily run using cron or GitHub Actions.

## Running the pipeline

python run_pipeline.py
## Running the review app

python review_app/app.py
